Phase 3 turns your KSB list into a complete curriculum design.

- In Modules 10 and 11 you set the unit structure and sort KSBs into it.
- In Modules 12 and 13 you set a level for every KSB and map assessment methods.
- In Module 14 you generate indicative content.
- In Module 15 you size the course into GLH, TQT and credit.

## Module 10: Unit Structure

### What Module 10 does

Module 10 inspects your design rules documentation and picks one of six pathways (A to F). The pathway tells Module 11 how to sort your KSBs into units and learning outcomes.

### How to complete Module 10

1. Select **Decide pathway**.
2. Review the result. The selected pathway and its description appear under 'SELECTED PATHWAY', with supporting evidence and a list of 'Pathway-Driving Inputs'. Each input is marked as detected or not detected.

The decision is read-only, but you can select **Re-run decision** in the top right corner. If you need a different pathway, you may need to go back and change earlier modules.

### How to continue from Module 10

When you're happy with the pathway, select **Approve and Continue to Module 11**.

## Module 11: Sorting Functions

### What Module 11 does

Module 11 assembles your validated KSBs into a course content tree, using the pathway selected in Module 10. In the tree, units contain learning outcomes, and learning outcomes contain KSBs. The synthetic panel reviews each learning outcome.

### How to complete Module 11

1. Select **Run Sorting**. A progress bar with timestamps appears. This can take a few minutes on large sets of KSBs.
2. Review the course content tree, which appears below when sorting is complete. It lists the units one by one.
   - Select a unit's arrow icon to expand it. Its learning outcomes appear, with their KSBs listed below each one. Each KSB is categorised, for example as 'comprehension'.
   - When you expand a learning outcome, the synthetic panel review appears under it, as in earlier modules.
   - Learning outcomes can be marked 'Panel flagged' or 'Oversized'. 'Oversized' means the outcome should be split in two.
3. To edit the tree, use the **Review** / **Edit** toggle in the top right. After sorting, it's in review mode. In edit mode you can:
   - rename units, outcomes and KSBs
   - drag and drop to reorder them
   - move KSBs between outcomes, and outcomes between units, one at a time or in bulk
   - delete and restore items (deletions aren't final until you approve the module)
   - act on oversized outcomes using the panel's suggested moves.
4. Place any KSBs that aren't assigned to an outcome. You can't approve the module until they're all placed.

To restart the process, select **Re-run sorting** in the top right.

### How to continue from Module 11

Every unit must have at least one active learning outcome assigned to it. You may need to go back and change earlier modules to achieve this.

When you're happy with the course tree, select **Approve and Continue to Module 12**. If any flagged learning outcomes remain, a pop-up asks whether you still want to approve before moving to Module 12.

## Module 12: Set & Confirm Content Levels

### What Module 12 does

Module 12 sets an appropriate level for every KSB from earlier modules. It assigns each KSB an RQF level between 1 and 8, for you to review against the qualification's level. If a profile fails, the synthetic panel reviews the mapping.

### How to complete Module 12

1. Select **Run Levelling**. A progress bar with timestamps appears. When levelling is complete, the level grid appears below it.
2. Review the grid. Each unit and learning outcome shows a '% at target' badge.
   - Select a unit's arrow to expand it and show its learning outcomes and their KSBs.
   - Each KSB shows its listing and its level band. Next to the level band, a status shows whether the level is 'at target', 'within ±1' or 'out of range'.
   - Where decisions are flagged, the synthetic panel review appears.
3. To change a KSB's level, use its dropdown menu. This may change its status and the '% at target' for its learning outcome.

After manual changes, select **Re-check Levelling** to test the levels again. To restart, select **Re-run Levelling**.

### How to continue from Module 12

Level quality is advisory throughout Module 12, so out-of-range KSBs don't stop you continuing. When you're happy with the levels, select **Approve and Continue to Module 13**.

## Module 13: Determine / Map Assessment Methods

### What Module 13 does

Module 13 maps each unit to one or more assessment methods. The verb domains of each unit's KSBs become 'affordances', which are mapped to the least complex valid set of methods. Every method can be traced back to the KSBs it assesses. The synthetic panel reviews the result.

### How to complete Module 13

1. Select **Run Mapping**. A progress bar with timestamps appears. When mapping is complete, a mapping grid appears below it.
2. Above the grid, expand **Panel review of the assessment mapping** to see any assumptions the panel has flagged.
3. Expand each unit in the grid to review it. You'll see the number of affordances and the chosen assessment methods. Each method has a confidence percentage, a rationale and a traceability disclosure. Expand the traceability disclosure to see which KSBs the method assesses, and why.
4. Change the methods if you need to:
   - To add a method, use the **Add a method…** drop-down below the listed methods. There are 16 to choose from, for example written examination, portfolio, practical demonstration, project and professional discussion.
   - To remove a method, select its **X** icon. You can't undo this.
5. After making changes, select **Re-check with panel**.

### How to continue from Module 13

A unit with no method shows a warning but doesn't stop you continuing. When you're happy with the assessment mapping, select **Approve and Continue to Module 14**.

## Module 14: Indicative Content

### What Module 14 does

Module 14 generates indicative content for each KSB. It works out the format from the qualification's perimeters, and the themes from earlier modules. You can then review and edit the content.

### How to complete Module 14

1. Select **Generate content**. A progress bar with timestamps appears, and the content is generated unit by unit.
2. When generation is complete, the synthetic panel review appears above the indicative content. It shows any concerns the panel raised. If there are none, a badge in the top right reads 'Panel approved the content'.
3. Review the indicative content, which is listed under every KSB. For each KSB you can:
   - select **+** to add content
   - select the pencil icon to edit existing content
   - select the learning assistant icon to update the content with AI.
4. Optionally, once you've reviewed or edited all the indicative content, select **Equality & inclusivity check**. This is an advisory review against the protected characteristics in the Equality Act 2010. It flags any issues it finds, which you can fix by editing the content as above.

### How to continue from Module 14

When you're happy with the indicative learning content, select **Continue to Module 15**.

## Module 15: Size Course

### What Module 15 does

Module 15 spreads learning time across the course structure. It estimates guided learning hours (GLH) and unsupervised hours, then adds these up through the learning outcomes and units to calculate total qualification time (TQT) and credit. Credit is TQT divided by 10.

### How to complete Module 15

1. Select **Run Sizing**. A progress bar with timestamps appears.
2. When sizing is complete, a message confirms that all units are correctly sized. Below it, a decision log describes the decisions made, with a quantitative analysis of the prescribed GLH and TQT.
3. Review the units, which are listed below the decision log with their learning outcomes. For each outcome, every piece of indicative content shows its GLH, unsupervised hours (UNSUP) and TQT.
4. To change the hours, type over the GLH or UNSUP value. TQT is calculated automatically. Shybird Define flags any changes that fall outside the target, and you can see these at the top of the page.

To restart the process, select **Re-run sizing** in the top right.

### How to continue from Module 15

Sizing outside the targets is flagged but doesn't stop you continuing. When you're happy with the course sizing, select **Approve and Continue to Module 16**.
