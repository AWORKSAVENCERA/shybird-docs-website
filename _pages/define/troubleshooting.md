## I can't find a sign-up page

There isn't one. Shybird Define is invite-only. Ask an administrator to invite you. See [How do I get an account?]({% link _pages/define/sign-in.md %}#how-do-i-get-an-account)

## The app shows 'Please open on desktop'

Shybird Define only works on a desktop browser. Open it in a browser on a laptop or desktop computer, with the browser window at full size.

## My 'Approve and Continue' button is greyed out

The module's minimum requirements haven't been met yet. The button, or a message near it, tells you what's missing. For example:

- 'Categorise N documents before continuing'
- 'N KSBs still need a learning outcome'
- 'Run panel review before approving'.

## A step is stuck on a progress bar

Heavy steps run in the background. It's safe to leave the page. When you come back, it will have updated. If the step failed, a red banner explains why and lets you run it again.

## A document failed to process

- In Module 0, delete the file and upload it again.
- In Module 1, if embedding failed, select the document's **Retry** button.

## I changed an earlier module. Why did later ones reset?

Later modules build on earlier ones, so editing and approving an earlier module again resets everything after it. To keep that module's own data, use **Reopen to edit**. See [Can I re-run a module I've finished?]({% link _pages/define/key-concepts.md %}#can-i-re-run-a-module-ive-finished)

## I deleted a project by mistake

It's in Trash for 90 days. Open **Trash** and select **Restore**.

## Where's the finished document?

Once the project is complete, download it from Module 18, from the completion screen, or by selecting the three-dot button on the project's dashboard card and then **Download**. See [Your final deliverables]({% link _pages/define/deliverables.md %}).

## The starred or favourites feature isn't showing

It's switched off in this version.
