Phase 5 assembles and publishes your qualification. In Module 17 you generate and edit the full specification. In Module 18 you format, preview, download and publish the finished document.

## Module 17: Specification Generation

### What Module 17 does

Module 17 assembles the whole qualification into a specification you can edit. It draws on the work from all the previous modules to create the structural content, such as units, learning outcomes and KSBs.

### How to complete Module 17

1. Select **Generate specification**. A progress bar with timestamps appears. When generation is complete, the number of sections and placeholders appears at the top of the page.
2. Review the sections of the specification, which are listed in the field below. Each section has a category, for example 'Introductory'.
   - Expand a section to preview and edit it. Switch between the **Preview** and **Edit** icons, and select **Save** to confirm your changes.
   - A section may be flagged 'Missing Source'. If so, its preview includes a sentence explaining any assumptions Shybird Define had to make, or any gaps that remain.
3. Download your work if you want to. Select **Download specification (Word)** or **Download decision log (Word)**. Both go to your downloads folder.

To restart the process, select **Regenerate specification** in the top right.

### How to continue from Module 17

Tick **Mark specification as ready**. When you're happy with the specification, select **Approve and Continue to Module 18**.

## Module 18: Final Publication

### What Module 18 does

Module 18 is where you format the approved specification for publication. This final stage changes only the layout and typography, not the content. You choose how the document looks, preview it live, download it and publish it to complete the project.

### How to complete Module 18

When you open the page, Shybird Define automatically builds a first formatted version with generic styling. A live preview pane shows your chosen style as you change it.

Use these tools to refine the document:

| Tool | What you can change |
| --- | --- |
| Page | The page size and margins. |
| Text | The font, font size and paragraph alignment. |
| Headings | The font, font size and colours for each heading type. |
| Lists | The markers and spacing in lists. |
| Tables | The table body, colours, padding and headers. |
| Header & Footer | The document's header and footer. |
| Cover | Upload a logo or full-cover image, or switch a title page on or off. |
| Themes | Start from a built-in theme or one of your own saved presets. |
| Export | Download the document as Word or PDF. The 'Internal review version' option keeps source metadata and review flags in an appendix. |

You must select **Save formatting** in the bottom right to save any formatting changes.

The page also offers:

- **A development record (audit trail)** to download. It's a full Word or PDF record of every module's inputs and outputs, panel decisions, scores, sizing reasoning and change logs.
- **A publication-readiness report**, summarising what was formatted. It shows the number of sections formatted and flags any review flags that haven't been resolved, for your awareness.

The internal review version can't be downloaded again after you complete Module 18, so download it first if you need it.

### How to finish the project

Select **Approve & complete project**. A 'Successfully Generated' completion screen confirms the project is done. It offers **Continue to Dashboard** and **Download**, which lets you download the specification and the audit trail, each as a PDF or Word document.

After this, the project shows on the dashboard as 'Completed' rather than 'In progress'.
