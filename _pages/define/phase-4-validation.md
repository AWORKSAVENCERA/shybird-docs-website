Phase 4 benchmarks your course design against comparable regulated qualifications. In Module 16, Shybird Define checks overlap in purpose, level and unit content, so that your qualification stays eligible for funding.

## Module 16: Benchmarking

### What Module 16 does

Module 16 searches the government register of regulated qualifications for qualifications similar to the one you're developing, to check that yours stays eligible for funding. It runs three overlap checks on comparable qualifications:

- purpose
- level
- unit content.

The panel then judges whether the overlap is acceptable, which affects funding eligibility.

### How to complete Module 16

1. Select **Run benchmarking**. A progress bar with timestamps appears.
2. When benchmarking is complete, the top of the page lists the number of candidates found, the number of specifications compared and the number of qualifications found to be too similar. Under the progress bar, Shybird Define states whether benchmarking passed. If it finds no comparable candidates, it says so.
3. Review the **Similarity Table** field, which shows how many candidates were found and compared. Select a candidate to see the purpose comparison and the unit-content similarity.
4. Read the **Panel Feedback**, which sets out the overlap findings and recommended actions.
5. Check the funding rules compliance results, listed below the panel. They flag any warnings that need more information. Warnings don't block you, but you may want to use the module roadmap to go back and change other parts of the qualification in earlier modules.

To restart the process, select **Re-run benchmarking**.

### How to continue from Module 16

Benchmarking is advisory and doesn't stop you continuing. If the overlap is high, consider revising the structure and running benchmarking again. When you're happy with the benchmarking review, select **Approve and Continue to Module 17**.
