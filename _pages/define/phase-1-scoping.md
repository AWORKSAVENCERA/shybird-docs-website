Phase 1 creates your project and defines its scope. In Module 0 you name the project and upload your organisation's strategy documents. In Module 1 you attach the reference material that shapes the qualification. In Module 2 you confirm and lock the qualification's parameters before research begins.

## Module 0: Project Creation

### What Module 0 does

Module 0 creates your project, and it's where you start describing the qualification. After you name the project, you upload documents that describe what the qualification will become. Shybird Define reads them and pulls out structured facts for you to review, such as the title, level, hours, KSBs, units and learning outcomes.

We recommend you upload, at a minimum, documents describing your product strategy and its business case.

### How to complete Module 0

1. Type a name under **Project Name**. It saves automatically.
2. Upload documents that describe what the qualification will become. Select **Browse Files** or drag and drop them onto the page. You must upload at least one file, and you can upload as many as you like.
   - Shybird Define accepts PDF, DOCX and TXT files of up to 20 MB each. You can import several at once.
   - A card appears for each file with a status of 'Processing…', 'Processed' or 'Failed'. The page updates the status automatically.
   - If a file fails, delete it and upload it again.
   - To preview a processed file, select its eye icon. To delete it, select its trash icon.
3. When your documents are processed, select **Run Extraction** in the bottom right. Extraction takes roughly 30 to 90 seconds, and a bar at the bottom shows its progress. You can't stop extraction once it begins. If it fails, an error message appears under the progress bar. Select **Run Extraction** again.
4. When extraction finishes, the bar changes colour and reads 'Extraction Complete'. Select it to open the review page.
5. Review the qualification metadata. This is a summary of the extracted information, covering the intended learner, prescribed KSBs, the unit structure and the assessment design. To see where a data point came from, select the icon next to its title.

The extracted information is read-only. Some data points may be flagged 'Needs Review', usually because the extraction looks incomplete or incorrect. To change a value, edit the source document, upload it again and re-run extraction.

### How to continue from Module 0

When you're happy with the extraction results, select **Approve and Continue to Module 1**.

## Module 1: Context Documents

### What Module 1 does

Module 1 collects the reference material that shapes what the qualification must contain and how it should read. Unlike Module 0, these documents cover regulator rules, an example awarding organisation specification and sector verb banks. You can also add shared knowledge-base documents that an administrator has published. Together, these become the project's retrieval context, which later modules use.

### How to complete Module 1

1. Upload your reference documents. Shybird Define accepts PDF, DOCX, CSV, XLSX and XLS files of up to 10 MB each. They appear under **Uploaded Documents**.
2. Categorise each document. This is required. Choose one of:
   - 'Ofqual general rules of recognition'
   - 'Example qualification (AO formatting template)'
   - 'Sector-specific verb bank'.

   The card then updates to show how many elements were extracted from the file.
3. Manage your documents if you need to:
   - To disable a document, use the toggle in the top right of its card. Shybird Define won't use a disabled document for retrieval, and you can switch it back on later.
   - To remove a document entirely, select the trash icon in the bottom right of its card.
   - If a document's embedding failed, select its **Retry** button.
4. In the **Shared Knowledge Base** selector, tick each document you want this project to draw on. The documents are organised by category. If there are none, you're prompted to ask an administrator to upload some.

### How to continue from Module 1

When you're happy with the uploaded documents and your Shared Knowledge Base selection, select **Approve and Continue to Module 2**.

## Module 2: Perimeter Validation

### What Module 2 does

Module 2 is a checkpoint where you confirm and lock the qualification's scope, called its perimeter, before any generative research begins. It gathers everything from Modules 0 and 1 into one form, which you can edit in full.

### How to complete Module 2

Module 2 shows several fields on one page. Every field is filled in with data extracted in the previous two modules.

1. Select the downward arrow on a field's card to expand it.
2. Review and edit it. You can edit text for specific values, or select and remove parameters.
3. Select **Save changes** in the bottom right of the field to save your changes.

The fields are:

- **KSB generation** - toggles that control whether the later modules produce knowledge, skills and behaviour statements.
- **Credit values** - a toggle for including credit values in the final specification.
- **Qualification metadata** - the title, awarding organisation, sector, occupation, RQF level (1 to 8), GLH, TQT, whether the qualification is regulated, and its purpose.
- **Assessment design** - the assessment types, any synoptic requirement, grading, structure, rules of combination, methodologies and assessment perimeters.
- **Intended user** - a description, age, English and maths requirements, and any prior education or experience.
- **Knowledge, Skills & Behaviours** - the prescribed KSBs from your design rules and the gaps in your business case. You can add more knowledge statements and gaps.
- **Prescribed structure** - units, learning outcomes and the mapped KSBs.
- **Context summaries** - read-only here. Edit these in Module 1.

### Funding rules compliance checks

A 'Funding rules compliance' panel runs automatically. It checks all the perimeters across these fields against GOV.UK funding approval rules. It shows counts of warnings, passes and checks that don't apply, and explains each check.

The warnings are advisory and don't block you. Editing a field marks the check as 'stale'. Select **Re-run** to refresh it.

### How to continue from Module 2

The title, sector, occupation, RQF level and regulated status must all be set.

Once the module is complete, a **Download** button appears in the bottom right. Use it to download the perimeter as a PDF or Word document.

If you later use the module roadmap to return to Module 2 and edit the perimeters, Modules 3 onwards reset, because the research depends on them. You're warned before this happens.

When you're happy with the perimeter, select **Approve and Continue to Module 3**.
