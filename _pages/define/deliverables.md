When a project is complete, Shybird Define produces the following documents.

| Deliverable | Formats | Where to get it |
| --- | --- | --- |
| Qualification specification (public view) | PDF, Word | The Export tool in [Module 18]({% link _pages/define/phase-5-publication.md %}#module-18-final-publication), the Module 18 completion screen, or the three-dot button on the project's dashboard card. |
| Qualification specification (internal review version, with review flags and metadata) | PDF, Word | The Export tool in Module 18 ('Internal review version'). You can't get this again after you complete Module 18. |
| Development record (audit trail) | PDF, Word | The Module 18 completion screen. |
| Decision log | Word | [Module 17]({% link _pages/define/phase-5-publication.md %}#module-17-specification-generation). |
| Perimeter summary | PDF, Word | [Module 2]({% link _pages/define/phase-1-scoping.md %}#module-2-perimeter-validation). |
