You create and continue projects from the dashboard. A project is the development of one qualification across 19 modules.

## How do I create a project?

Create a new project each time you want to draft a new qualification.

1. On the dashboard, select **Create New Project** in the top right. You're taken straight to the module roadmap.
2. Start with Module 0.

You don't need to give any details before you create the project. Shybird Define gathers everything (title, occupation, level, documents and so on) inside the modules, starting with Module 0. Until Module 0 gives the project a name, it shows as 'Untitled-…' on the dashboard.

## How do I use the module roadmap?

After you create a project, you're taken to its 'Module Roadmap' page. Scroll down to see all 19 modules listed step by step, with Module 0 at the top.

Each module appears as a card showing its number, its progress status and a one-line description. Module 0 starts as 'In Progress'. All the other modules are greyed out and marked 'Locked'.

Select a card to open that module. Each module has its own screen for your input. If a module needs information from earlier steps, it tells you what's required, and you can't do anything more in it until that's done. When you're in a module, the sidebar changes to show the stages of the module roadmap.

From inside a module, use the buttons in the top left to go back to the project's module roadmap or the dashboard.

[How the module roadmap works]({% link _pages/define/module-roadmap.md %}) explains each module in detail.

## How do I resume, rename or download a project?

You can resume any project from the dashboard, rename a project at any time, and download completed projects.

- **Resume** - select anywhere on the project's card. You return to the module you were last on.
- **Rename** - set or change the project name in Module 0. It saves automatically when you click away.
- **Download** - once a project is 'Completed', select the three-dot button on its card, then **Download**, to get the finished qualification document. Module 18 and the completion screen have more export options. See [Your final deliverables]({% link _pages/define/deliverables.md %}).

## How do I delete and restore a project?

Deleting a project is a soft delete. The project goes to 'Trash', so it isn't gone forever.

1. On the project card, select the three-dot button, then **Delete**, and confirm. The project moves to 'Trash' and no longer appears on the dashboard.
2. To find it again, open **Trash** from the sidebar. Each item shows when it was moved to Trash and an 'Auto-deletes in N days' countdown. Projects are kept in Trash for 90 days.
3. From Trash you can either:
   - select **Restore** to put the project back on your dashboard, or
   - select **Delete permanently**. This can't be undone and removes all of the project's data.
