## Our commitment

We want everyone to be able to use Shybird, including people who use a keyboard instead of a mouse, a screen reader, a magnifier, speech recognition or other assistive technology.

This statement covers:

- Shybird Define
- Shybird Design
- Shybird Deliver
- the Shybird Admin Centre
- this documentation website

We build and test these products to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. This is the international standard for accessible websites and apps.

Each product also has its own accessibility page at `/accessibility`. You'll find a link to it on the Design and Deliver sign-in pages, below the sign-in box on the Admin Centre sign-in screens, and in the Admin Centre footer.

## What you can do

### Use a keyboard only

You can use every part of Shybird without a mouse or touch screen.

- **Skip to main content.** Press `Tab` once on any page and the first thing you reach is a **Skip to main content** link. Press `Enter` to jump past the menu.
- **See where you are.** Whatever you've selected has a clear outline around it.
- **Never get stuck.** `Tab` always moves you on. You can always leave a pop-up, menu or field with the keyboard.
- **Pop-ups behave the same way everywhere.** When a pop-up opens, focus moves into it and stays there until you close it. `Esc` closes it and takes you back to the button that opened it. The page behind is switched off while the pop-up is open.
- **Menus and dropdowns** open with `Enter`, `Space` or `↓`, and close with `Esc`. You can move through the options with the arrow keys or `Tab`.
- **Moving items without dragging.** Anywhere you can drag items into a different order, there is a keyboard way to do the same thing:
  - In Define, use the **Move up** and **Move down** buttons next to each item. The new position is read out.
  - In the Design course builder, each block has a menu with options to move or delete it.
- **Lesson player.** In Deliver, while a full-screen lesson is open, `Tab` only moves through the lesson and never reaches the page behind it.

See [Keyboard keys](#keyboard-keys) below for a full list.

### Use a screen reader

- **Buttons, links and form fields have names** that a screen reader reads out. Where a button acts on one item, its name says which, for example "More actions for" followed by the course name, or "Resend invitation" followed by the email address.
- **Messages are read out.** Pop-up messages (sometimes called toasts), such as "Settings saved", are announced:
  - Error messages are announced straight away and stay on screen until you close them.
  - Other messages stay for about 10 seconds. They pause while your pointer or keyboard focus is on them, and each one has a close button.
- **Results you can't see are announced too**, such as a code being sent when you sign in, a failed autosave, or an upload that didn't work.
- **Form errors** appear next to the field they belong to and are linked to it. When you submit a form with a mistake, focus moves to the first field that needs fixing, and the message is read out.
- **Buttons that can't be used yet** tell you what's missing when you press them, instead of doing nothing.
- **Tables, headings and expanding sections** are marked up properly. Table cells are read with their row and column headings, and expanding sections (such as the Deliver FAQs) say whether they are expanded or collapsed.

### Zoom in and use a small screen

- You can zoom up to 400% without having to scroll sideways to read a line.
- Pages fit on screens as narrow as 320 pixels, so they work on phones and tablets.
- Text and important parts of the screen have enough colour contrast to be read easily.

### Watch videos with captions

When a video lesson is added, or its video is replaced, captions are created for it automatically.

### Reduce motion

If you turn on your device's reduce motion setting, Shybird respects it. See [Zoom and display](#zoom-and-display) for how to turn it on.

## Keyboard keys

These keys work across Define, Design, Deliver and the Admin Centre.

### Moving around

| Action | Windows | Mac |
| :---- | :---- | :---- |
| Go to the next link, button or field | `Tab` | `Tab` |
| Go to the previous one | `Shift` + `Tab` | `Shift` + `Tab` |
| Skip the menu and go to the main content | `Tab` once on a new page, then `Enter` on **Skip to main content** | `Tab` once on a new page, then `Return` on **Skip to main content** |
| Open a link | `Enter` | `Return` |
| Press a button | `Enter` or `Space` | `Return` or `Space` |
| Scroll the page | `↑` `↓`, `Page Up` / `Page Down` | `↑` `↓`, `Fn` + `↑` / `Fn` + `↓` |
| Go to the top or bottom of the page | `Home` / `End` | `Fn` + `←` / `Fn` + `→` |
| Go back to the previous page | `Alt` + `←` | `Cmd` + `[` |

### Forms

| Action | Windows | Mac |
| :---- | :---- | :---- |
| Tick or untick a checkbox, turn a switch on or off | `Space` | `Space` |
| Send a form | `Enter` in a field, or `Enter` on the button | `Return` in a field, or `Return` on the button |
| Six-box sign-in code: go back one box | `Backspace` in an empty box | `Delete` in an empty box |
| Six-box sign-in code: paste the whole code | `Ctrl` + `V` in the first box | `Cmd` + `V` in the first box |

### Dropdowns, menus and pop-ups

| Action | Windows | Mac |
| :---- | :---- | :---- |
| Open a dropdown | `Enter`, `Space` or `↓` | `Return`, `Space` or `↓` |
| Move through the choices | `↑` `↓`, or `Tab` / `Shift` + `Tab` | `↑` `↓`, or `Tab` / `Shift` + `Tab` |
| Choose the highlighted option | `Enter` or `Space` | `Return` or `Space` |
| Move between items in an open pop-up | `Tab` / `Shift` + `Tab` | `Tab` / `Shift` + `Tab` |
| Close a dropdown, menu or pop-up and go back to the button that opened it | `Esc` | `Esc` |
| Move an item up or down in a list (Define) | `Tab` to **Move up** or **Move down**, then `Enter` | `Tab` to **Move up** or **Move down**, then `Return` |

### Zoom and display

| Action | Windows | Mac |
| :---- | :---- | :---- |
| Zoom in or out (up to 400%) | `Ctrl` + `+` / `Ctrl` + `-` | `Cmd` + `+` / `Cmd` + `-` |
| Go back to normal size | `Ctrl` + `0` | `Cmd` + `0` |
| Turn off animations | Settings › Accessibility › Visual effects › turn **Animation effects** off | System Settings › Accessibility › Display › turn **Reduce motion** on |

### Screen readers

| Action | Windows | Mac |
| :---- | :---- | :---- |
| Turn the built-in screen reader on or off | Narrator: `Ctrl` + `Win` + `Enter` | VoiceOver: `Cmd` + `F5` |
| Read the next item | Narrator: `Caps Lock` + `→` | VoiceOver: `Ctrl` + `Option` + `→` |
| Jump between headings | Narrator (scan mode), NVDA or JAWS: `H` | VoiceOver: `Ctrl` + `Option` + `Cmd` + `H` |
| Stop reading | `Ctrl` | `Ctrl` |

### If Tab skips links on a Mac

On a Mac, `Tab` may skip links and buttons until you turn on keyboard navigation:

1. Open System Settings › Keyboard.
2. Turn on **Keyboard navigation**.
3. In Safari, also open Safari › Settings › Advanced and turn on **Press Tab to highlight each item on a webpage**. Or hold `Option` while you press `Tab`.

## Known limitations

We know about these problems and are working on them:

- **Older videos may not have captions.** Captions are created automatically only for videos added or replaced since this was introduced. If a video you need has no captions, [contact us](#report-a-problem-or-ask-for-another-format) and we'll help.
- **Some success messages may not be read out by Narrator in Chrome.** For example, in Define, the message after you save your profile was not spoken in one test with Windows Narrator in Chrome. Error messages are read out. If this affects you, try Microsoft Edge with Narrator, or NVDA. We're still testing these.
- **Third-party content.** Content from other services that appears in Shybird, such as embedded videos or documents your organisation uploads, may not be fully accessible. We can't always control it, but tell us if it's a barrier and we'll look for an alternative.

## How we test

- **Every change is checked automatically** against all WCAG 2.2 level A and AA rules that a tool can check. A change that adds a serious accessibility problem can't be released.
- **We check by hand** before each release and after big changes to the screens. This covers using a keyboard only, seeing where focus is, using a screen reader, zooming, colour contrast, moving items without dragging, and motion.
- **We test with screen readers**, including Windows Narrator.

The latest automatic check of Define, Design and Deliver found no serious or critical accessibility problems on the sign-in and other public pages. The Admin Centre is checked in the same way.

We keep a record of every check and fix, with the date and result. Customers can ask to see the test reports during procurement.

## Report a problem or ask for another format

If something in Shybird is hard or impossible for you to use, or you need information in a different format, tell us.

**Email:** [pmo@avencera.ai](mailto:pmo@avencera.ai)

If you're a learner in Shybird Deliver, you can also [contact support from inside Deliver]({% link _pages/deliver/get-help.md %}#contact-support).

Please tell us:

- the product and the page or feature you were using
- what happened
- any assistive technology you use, such as a screen reader or magnifier
- the format you'd like, if you're asking for information in another format

### What happens next

1. We'll reply to say we've received your message within five working days.
2. We log the problem and give it a priority based on how badly it affects people. Problems that stop you completing a task come first.
3. We'll tell you what we're doing about it, and let you know when it's fixed.
4. If you need something now, we'll find another way to give you the information or complete the task.
