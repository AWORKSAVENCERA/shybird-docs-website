You'll find the FAQs and support on the Technical Questions page. To get there, select **Technical Questions** (the headphones icon) in the menu. If you're in a module, select **Exit Module** to go back to your list of modules first.

For questions about your course content, ask the [Learning Assistant]({% link _pages/deliver/learning-assistant.md %}) instead.

## Read the FAQs

1. Select **Technical Questions** in the menu.
2. Select **Frequently Asked Questions**.

## Contact support

If the FAQs don't answer your question, send a request to the support team.

1. Select **Technical Questions** in the menu.
2. Select **Contact Us**.
3. Work through the quick fixes listed. Tick the checkbox next to each one once you've tried it.
4. When you've ticked them all, select **Get Support**.
5. Fill in the form, then select **Send Request**.

To see requests you've already sent, select **My Requests** in the top right.
